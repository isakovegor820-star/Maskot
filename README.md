# Маняша Voice

Прототип голосового маскота на `gemini-3.1-flash-live-preview`. Браузер подключается к Gemini напрямую через одноразовый короткоживущий токен, поэтому постоянный API-ключ остаётся только на сервере, а аудиопоток не проходит через приложение.

## Запуск

1. Отзовите ключ, который был опубликован в чате, и создайте новый в [Google AI Studio](https://aistudio.google.com/api-keys).
2. Откройте `.env.local` и добавьте новый ключ:

   ```env
   GEMINI_API_KEY=новый_ключ
   PORT=43829
   ```

3. Запустите приложение:

   ```bash
   npm start
   ```

4. Откройте [http://localhost:43829](http://localhost:43829).

Для разработки с автоматическим перезапуском используйте `npm run dev`.

## Проверки

```bash
npm test
```

## Архитектура

- `server.mjs` раздаёт статические файлы и создаёт ограниченный ephemeral token через Gemini API.
- `public/app.js` управляет WebSocket-сессией, микрофоном, VAD, транскрипцией и воспроизведением.
- «Друг 18+» — внимательный напарник: учитывает тему, слушает без непрошеных советов, помогает с учётом целей и ограничений, может аргументированно не согласиться. Мат по умолчанию свободный и уместный, не обязательный. «Матерный друг» сохраняет мат в каждом ответе. Можно выбрать речь без мата. Если Gemini вернул текст без аудио, браузер пробует резервный русский голос; его тембр и выразительность зависят от системы.
- Ручная проверка настоящих ответов: `node scripts/check-voice.mjs sample friend always 'Как дела?'`. Использует API-ключ и квоту Gemini; сохраняет только сгенерированные WAV и транскрипции в `voice-checks/sample/`. Автоматическая оценка аудио: `node scripts/review-voice.mjs voice-checks/sample/1.wav` (второе мнение модели, не гарантия правильности каждого ударения).
- При плановом сбросе WebSocket приложение использует session resumption, а при повторном сбое автоматически создаёт новую короткоживущую сессию.
- `capture.worklet.js` передаёт 16 kHz PCM-аудио небольшими чанками.
- `playback.worklet.js` воспроизводит поток 24 kHz и очищает очередь при перебивании.
- `data/knowledge.json` — редактируемая база знаний о продукте, доступная модели через tool call.

## Память и приватность

«Что Маняша помнит» показывает до 40 заметок по 400 символов: сведения о тебе, предпочтения, проекты, цели и события. Можно добавить, исправить, удалить или отключить память. Она хранится в localStorage этого браузера и сайта — не в аккаунте и не синхронизируется между устройствами. Очистка данных сайта удаляет заметки.

При включённой памяти заметки отправляются Gemini вместе с настройками разговора. Инструмент сохранения требует цитату из недавних слов пользователя и сообщает успех только после записи в хранилище. Это проверка происхождения цитаты, не гарантия правильной интерпретации: заметки стоит просматривать. Не сохраняйте секреты. При голосовом удалении после ответа запускается свежая сессия без старого контекста; при изменении памяти в другой вкладке текущий разговор останавливается. Изменять заметки вручную можно между разговорами.

Последние 24 реплики остаются только в оперативной памяти страницы и помогают при переподключении. Они не записываются в localStorage. Полная стенограмма видна до перезагрузки страницы. Удаление заметки не удаляет уже отображённую стенограмму или данные, ранее переданные провайдеру.

## Актуальные сведения

`search_web` обращается через сервер к Gemini с Google Search. Источники и поисковые подсказки отображаются под ответом. При квоте, таймауте или отсутствии источников инструмент возвращает явную ошибку — ответ нельзя выдавать за проверенный. Наличие ключа для голоса не гарантирует квоту поиска. Для запроса передаётся поисковая фраза, не вся личная память; голосовой модели предписано обезличивать её.

Голос и подбор слов вероятностные: настройки не гарантируют идеальную интонацию, каждое ударение или мат абсолютно в каждой реплике. Реальные проверки используют квоту API. `scripts/check-voice.mjs` сохраняет синтетическую тестовую память отдельно в `voice-checks/synthetic-memory.json`, не читая память браузера.

Постоянный ключ не отправляется в браузер и не должен коммититься в Git.
